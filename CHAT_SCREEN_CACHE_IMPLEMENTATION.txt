===============================================================================
OVERVIEW
===============================================================================

The chat screen now stores messages in local database (Hive) based on:
1. Conversation ID (chat ID)
2. Chat Type (one-to-one or group)
3. Current User ID (for one-to-one chats)

Storage Keys:
- One-to-one chats: messages_user_{chatId}_{currentUserId}
- Group chats: messages_group_{chatId}

===============================================================================
HOW IT WORKS
===============================================================================

FIRST TIME OPENING A CHAT:
┌─────────────────────────────────────────────────────────────┐
│ 1. User opens chat screen                                   │
│ 2. Check local database for cached messages                 │
│ 3. If empty → Show loader + Call API                        │
│ 4. API returns messages → Save to local database            │
│ 5. Display messages on screen                               │
│ 6. Mark as "API loaded" (won't call API again)              │
└─────────────────────────────────────────────────────────────┘

SUBSEQUENT OPENS (2nd, 3rd, ... times):
┌─────────────────────────────────────────────────────────────┐
│ 1. User opens chat screen                                   │
│ 2. Load from local database instantly (<100ms)              │
│ 3. Display messages immediately (NO LOADER)                 │
│ 4. NO API call (uses cached data)                           │
│ 5. Firebase real-time updates continue in background        │
└─────────────────────────────────────────────────────────────┘

EXAMPLE 1: First Time Loading Chat

Step 3: Display messages
```dart
setState(() {
```

===============================================================================
STORAGE STRUCTURE
===============================================================================

Hive Boxes Created:
├── messages_group_1          (Group chat ID 1)
├── messages_group_2          (Group chat ID 2)
├── messages_group_10         (Group chat ID 10)
├── messages_user_5_1         (User 1 ↔ User 5 chat)
├── messages_user_7_1         (User 1 ↔ User 7 chat)
└── messages_user_5_3         (User 3 ↔ User 5 chat)

Each box stores:
- Message ID (key)
- Message data (value): {
    id, chatId, senderId, senderName, text, type,
    timestamp, status, fileUrl, fileName, etc.
  }
