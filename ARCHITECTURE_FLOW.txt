===============================================================================
                      ERROR HANDLING & FALLBACKS
===============================================================================

1. NO INTERNET (First Launch)
   → Show error: "Connection required for first sync"
   → Retry button available

2. NO INTERNET (Subsequent)
   → Load from Hive cache instantly
   → Show offline indicator
   → Queue outgoing messages

3. API FAILURE
   → Fallback to cached data
   → Loader dismisses (no infinite loading)
   → Background retry

4. FIREBASE FAILURE
   → Hive data still accessible
   → Real-time updates paused
   → Manual refresh available

5. HIVE CORRUPTION
   → Auto-detect on init
   → Clear corrupt data
   → Force full resync from API
