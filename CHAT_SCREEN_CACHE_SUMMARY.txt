STORAGE STRATEGY
===============================================================================

GROUP CHATS:
Key Format: messages_group_{chatId}
Example: messages_group_5
Used For: All members access same group messages

ONE-TO-ONE CHATS:
Key Format: messages_user_{chatId}_{currentUserId}
Example: messages_user_10_1
Used For: Each user pair has separate storage

===============================================================================
HOW IT WORKS
===============================================================================

FIRST OPEN (User opens chat for 1st time):
1. Check cache → Empty
2. Call API → Get messages
3. Save to Hive → Cache for future
4. Display messages
5. Set flag → API won't be called again
Time: 2-3 seconds

SUBSEQUENT OPENS (2nd, 3rd, ... times):
1. Check cache → Has messages
2. Load from Hive → Instant
3. Display messages → No loader
4. Skip API call → Use cached data
5. Firebase sync → Background updates
Time: <100ms (95% faster!)
